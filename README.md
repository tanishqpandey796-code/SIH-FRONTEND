## 🌟 Overview
**Sahakar Gig Platform** is a cooperative-owned digital service marketplace that empowers **Labour Cooperative Societies** to directly connect verified skilled workers (electricians, plumbers, carpenters, caregivers, domestic helpers, and technicians) with households and institutional consumers.

Unlike commercial venture-backed aggregators that charge 25%–35% commissions and provide zero health benefits, Sahakar Gig Platform enforces a transparent **90-5-5 distribution model**:
- **90%** Direct to Worker Bank Account
- **5%** Worker Social Welfare & Health Shield (PM Suraksha Bima Yojana)
- **5%** Cooperative Society Patronage Dividend & Equipment Fund
- **0%** Private Intermediary Exploitation

## 🚀 Key Features

### 1. 🏠 Household Customer Portal
- **Canva & Stitch Visual Design**: Modern design aesthetics with high visual polish, stitched trust badges, and floating metric chips.
- **📡 Live HTML5 Canvas Radar**: 60FPS dynamic radar visualization scanning local 5km radius with live cooperative worker nodes.
- **📍 Smart Geo-Matching**: Real-time worker availability, distance tracking, and instant dispatch booking.
- **💳 100% Transparent Invoicing**: Itemized breakdown showing base fare, GST, direct worker payout, and social welfare contributions.
- **🚨 1-Click Emergency SOS**: 15-minute guaranteed dispatch for MCB fire hazards, pipe bursts, and caregiver emergencies.
- **🎚️ Live Fair-Wage Simulator**: Interactive slider to compare take-home earnings vs private aggregators.

### 2. 🛠️ Sahakar Worker Workspace
- **📥 Live Job Radar**: Real-time incoming calls near the worker with transparent payouts and one-click acceptance.
- **💰 Transparent Earnings & Patronage Dividend**: Detailed ledger showing monthly earnings and accumulated cooperative rebates.
- **🛡️ Social Security & Health Insurance Shield**: Integrated PM Suraksha Bima Yojana (₹2,00,000 accident cover) and cashless hospitalization.
- **🪪 Official Digital Cooperative Worker ID**: Government-recognized ID with QR biometric verification and police clearance stamps.

### 3. 🏛️ Federation Admin & Governance Dashboard
- **🔍 Worker Certification & Background Pipeline**: Real-time verification queue for Aadhaar biometric linkage, police clearance, and ITI certifications.
- **🏛️ Affiliated Societies Directory**: Registry of multi-state and district labour cooperative federations.
- **📊 Fair-Wage & Anti-Exploitation Metrics**: Compliance tracking ensuring zero commission violations.

## 🛠️ Technology Stack
- **Frontend Architecture**: Standalone React 18, Babel Standalone (zero build-step required).
- **Styling**: Vanilla CSS3 Design System with Stitch UI badging, Canva glassmorphism, responsive grid, and CSS variables.
- **Interactive Visuals**: HTML5 `<canvas>` 60FPS Cooperative Mesh Radar.
- **Server**: Lightweight HTTP Server / Python 3 HTTP Server.

## 📦 How to Run Locally

### Option 1: Using Python (Recommended)
```bash
python -m http.server 3000
```
Then visit: `http://localhost:3000`

### Option 2: Using Node.js
```bash
node server.js
```
Then visit: `http://localhost:3000`

### Option 3: Direct Browser Open
Simply double-click `index.html` in your file explorer to open it in any modern web browser!
